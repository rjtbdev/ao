# decisions (ADRs)

Architecture Decision Records. One file per non-obvious decision.

## Rules

- **Immutable once written.** If a decision is reversed, write a NEW
  ADR citing the old one. Don't edit history.
- **Numbered sequentially.** `NNNN-slug.md`, zero-padded to 4 digits.
- **Short.** One page or less. Format: Context, Decision, Alternatives,
  Consequences.
- **Date-stamped.** Include the date the decision was made.
